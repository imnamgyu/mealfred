① 원장님 설문

목적 한 줄

1년 계약을 제안하기 전에 — ① 이 비용(20명 원 기준 연 93.6만 원)이 실제로 어떤 돈(원 예산 / 학부모 부담 / 시 지원금)에서 나갈 수 있는지 ② 언제·누가 결정하는지 ③ 다른 원으로 퍼질 길(원장님 네트워크)이 있는지 파악.

  1. 지금 원에서 하고 있는 외부 프로그램(영어·체육·음악 등)을 알려주세요 — 과목 / 1인당 월 비용 / 비용이 나가는 곳(학부모 부담 · 원 예산 · 시 지원금)→ 가격 비교 기준과 '돈 나오는 주머니'를 현재 사실로 확인
  2. 그 업체들은 처음에 어떻게 알게 되셨어요? (다른 원장님 소개 / 영업 방문·전화 / 박람회 / 인터넷 검색 / 선생님 추천)→ 새 원들이 우리를 알게 될 경로를 역산
  3. 외부 업체와는 보통 어떤 단위로 계약하세요? (1년 / 학기 / 월) 중간에 바꾸거나 그만둔 적이 있다면 이유는?→ "1년 계약"이 이 동네 관행인지 + 해지되는 이유
  4. 부산시에서 나오는 특별활동비·행사비 지원(3~5세)은 지금 어떻게 받고 계세요? 다 쓰는 항목과 남는 항목이 있다면요?→ 2026년 신설된 '제3의 주머니'(시 지원 월 13.7만 규모)의 실제 흐름
  5. 작년에 요리·쿠킹 활동에 쓴 비용이 있다면 어떤 예산 항목(행사비 / 교재교구비 / 급간식비 등)에서 대략 얼마였나요?→ 우리 상품이 앉을 회계 자리
  6. 내년(2027학년도) 프로그램과 예산은 몇 월에, 어떤 절차로 정하세요? (원장님 단독 / 운영위원회 / 법인)→ 원별 영업 데드라인
  7. 학부모님께 새로 비용을 받기 시작한 가장 최근 사례가 있다면 — 무엇이었고, 어떤 절차를 거쳤고, 반응은 어땠나요?→ 학부모 부담 경로의 실제 난이도
  8. 올해 밀프레드 요리행사 중 사정상 진행 못 하고 넘어간 달이 있었다면, 어떤 사정이었나요?→ "매달 빠짐없이" 조건의 현실성 — 운영 책임자인 원장님께 묻는 게 자연스러움
  9. 동봉한 내년 커리큘럼 표에서 우리 원 여건상 어려워 보이는 메뉴가 있다면 체크해주세요 (알레르기 / 난이도 / 정리 부담 / 오븐·에어프라이어 없음) — 원에 에어프라이어나 오븐이 있는지도 함께요→ '지정 메뉴' 조건의 걸림돌을 메뉴 단위로 특정 (커리큘럼 2종은 오븐 필요)
  10. 원장님들 모임·연합회·단톡방에 속해 계세요? 최근 3개월 안에 거기서 화제가 된 업체나 프로그램이 있었나요?→ 다른 원으로 퍼질 길이 실제로 있는지
⚠️ 계약 제안(3,900원)은 설문에 넣지 않습니다. 설문과 별도로 원장님께만 전화 → 안내문+신청 카드 전달. 이유는 §③.

② 선생님 설문

목적 한 줄

1년 커리큘럼을 매달 진행할 때 선생님이 힘들지 않도록 키트와 자료를 고치기 위한 것 — 평가·확인이 아니라 도움 요청. 시간 재기·횟수 캐묻기 없음(불쾌·방어적 거짓 응답 방지 — 이사님 지침).

  1. 지금까지 한 요리행사 중 제일 수월하고 아이들 반응도 좋았던 메뉴는 무엇이었나요? (진행한 메뉴 체크리스트에서 선택)→ 성공 메뉴의 성공 요인을 커리큘럼 설계 기준으로
  2. 반대로 다시 하라면 조금 부담스러운 메뉴가 있다면? 어떤 점이 부담이었나요? (준비 / 당일 진행 / 뒷정리 / 아이들이 어려워함)→ 운영 난이도 최악 메뉴를 실명으로 — 2027 배치 전 교체 판단
  3. 만들고 나서 아이들이 잘 안 먹었던 메뉴가 있었나요?→ '만들기는 성공, 시식은 실패' 메뉴 — 편식 개선 가치와 직결
  4. 보내드린 조리도구 중 아쉬웠던 것(수량·크기·품질·세척)이 있다면? 원에 있는 도구를 대신 쓰신 적이 있다면 어떤 것이었나요?→ 실제 대체가 일어난 도구 = 키트의 확정 결함. 유료 전환 전 고쳐야 할 것
  5. 행사 준비부터 뒷정리까지 중에 "이것 하나만 바뀌면 훨씬 편하겠다" 싶은 것 한 가지는?→ 개선 우선순위를 현장이 직접 지목
  6. 요리행사 후에 학부모님 반응이 온 적이 있나요? (하원 때 말씀 / 키즈노트 댓글 / "레시피 알려달라" 문의) 어떤 메뉴 때였나요?→ 학부모를 실제로 움직인 결과물 — 원장님 결제 정당화의 근거
  7. 1년 중 요리행사 하기 힘든 달이 있다면 언제인가요? (원 행사·발표회 겹침 / 신학기 / 방학)→ 여러 원에서 같은 달이 나오면 커리큘럼 해당 월을 저부담 메뉴로 교체
v1.1에서 제거한 문항: 단계별 소요 시간(분) 실측 · 결번 횟수 · 세척 담당자와 시간 · 진행 위임 횟수 · 알레르기 조정 횟수 — 취조당하는 느낌 → 불쾌하거나 거짓 응답 위험. 결번 이력은 원장님 설문 8번으로 이동.

③ 왜 이렇게 짰나

계약 제안을 설문에 안 넣는 이유

무상으로 받아온 8곳에 "계약하시겠어요?"를 설문지로 물으면 예의상 "긍정 검토"만 나온다(거절 비용이 0이라서). 그래서 3단계로 분리:

  1. 설문 2종은 키트에 동봉 — 가격 얘기 0. (선생님이 가격 문서를 먼저 열면 "특활비 오른대요"가 학부모 채팅방으로 퍼짐)
  2. 원장님께 전화로 예고 → 안내문 + 신청 카드를 원장님께만 전달
  3. 진심은 행동으로만 판정: 자료 요청 < 조건 협상("학년도로 해달라") < 시작 월·인원 기재 < 신청 카드 서명 < 선납 의사·다른 원장님 실명 소개. 서명 이상 3곳+ → 다른 원 마케팅 GO / 0곳인데 협상 요구는 많다 → 가격 문제가 아니라 돈 나올 주머니 문제.

신청 카드 골격 (A5 양면)

  • 앞면 = "2027 파트너 원 조건" — 1년 함께한 원 전용 조건. "할인" 강조 금지: 0원으로 받아온 원에겐 3,900원이 할인이 아니라 인상으로 느껴짐. + "신청 안 하셔도 남은 2026년 회차는 끝까지 동일하게 진행됩니다" 명문(거절을 안전하게 — 예의상 긍정을 줄이는 유일한 방법).
  • 뒷면 = 신청서 — 시작 시점(1월/3월) · 예상 인원 · 결제 방식 기재란 + 어려운 경우 체크 3(통화 원함 / 자료 원함 / 계획 없음) + 소개란(맞을 것 같은 원장님 성함·연락처 — 사례금 없음: 보상이 붙으면 소개가 신호가 아니라 거래가 됨).

⑤ 응답을 어떻게 읽나

  • 8곳은 통계가 아니라 8개의 개별 케이스 — 집계 %가 아니라 원별 반응 단계 + 거절의 구체 이유가 산출물.
  • 성공 기준(미리 정해둠): 유력 2곳 중 1곳+ 계약 + 8곳 거절 이유 지도 + 실명 소개 1건+. 매출(최대 연 수백만 원)은 부산물 — 진짜 산출물은 유료 레퍼런스 원 · 거절 이유 지도 · 소개 네트워크.
  • 선생님 설문의 "부담 메뉴·힘든 달"이 여러 원에서 같은 답으로 수렴하면 → 개별 원 문제가 아니라 커리큘럼 구조 문제 → 해당 월 메뉴 교체.
  • 이 조사가 답 못 하는 것: 모르는 원(콜드)의 전환율·획득 비용 — 8곳은 상한선 참고치. 콜드 검증은 소개받은 원 + 별도 아웃바운드로.

⑥ 이사님 확정 대기 7건

횟수는 월 1회 × 총 12회로 확정됨(2026-08-24 이사님). 남은 결정:

  1. 지정 강도: 완전 지정 vs 월 2메뉴 중 원이 택1 — 권고 = 택1 (원장님들 최대 관심사가 '우리 원 차별화'라 자율성 완전 박탈은 반감)

  4. 결제 주기: 월별 정산 vs 선납 — 기존 "계산서 계좌이체 5% 할인"과 3,900원 중복 적용 여부 포함
  5. 진행 못 한 달 처리: 할인 취소? — 권고 = 그 달 안 대체일 + 완충(예: 연 10회 이상 진행하면 할인 유지)
  6. 우선 신청 마감일 + "파트너 원 조건" 문구 승인
  7. 대원칙.md 개정 승인: 지금까지 설문은 "세일즈 금지"가 원칙이었음 — 계약 제안 트랙을 별도로 신설하는 개정
