① 원장님 설문

목적 한 줄

6개월 함께한 경험과 3,900원 오퍼를 앵커로 — ① 이 가격이면 어떤 방식으로(원 예산/학부모 참여비) 현실적인지 ② 금액 기준선(1인당 얼마까지가 부담 없는 선인지) ③ 12개월 약정 vs 단발 중 무엇을 고르는지를 이번 한 번의 설문에서 파악.

인트로 문안(초안): "약속드린 무상 요리행사 지원이 올해로 마무리됩니다. 내년부터는 유료 프로그램으로 운영하게 되어, 그동안 함께해주신 원장님께 가장 먼저 의견을 여쭙니다. 솔직한 답변이 저희에게 가장 큰 도움입니다. (내년 진행 여부와 관계없이 올해 남은 회차는 끝까지 동일하게 진행됩니다.)"

  1. 지금까지 함께한 요리행사가 원 운영에 실제로 도움이 된 순간이 있었다면 어떤 것이었나요? (복수 선택) — 입소 상담 때 소개 거리 / 학부모 반응·문의가 옴 / 키즈노트·SNS에 올릴 거리 / 아이들 식습관 변화 / 선생님 수업 준비 부담을 덜어줌 / 특별히 없었다→ 6개월 체험에서 원장이 느낀 실제 가치 — 계약 설득 포인트가 무엇인지
  2. 내년에도 계속한다면, 지금 형태에서 꼭 바뀌어야 할 것 한 가지는 무엇인가요?→ 유료 전환 전 고쳐야 할 1순위를 원장이 직접 지목
  3. 동봉한 내년 커리큘럼 표에서 우리 원 여건상 어려워 보이는 메뉴가 있다면 체크해주세요 — 원에 에어프라이어나 오븐이 있는지도 함께요→ '지정 메뉴' 조건의 걸림돌을 메뉴 단위로 (커리큘럼 2종은 오븐 필요)
  4. 내년 정가는 1인분 4,900원입니다. 12개월 함께해주시는 원은 1인분 3,900원 + 배송비 무료로 진행하려 합니다. 이 비용이라면 우리 원에서는 어떤 방식이 현실적일까요? — 원 예산으로 진행 / 학부모 안내 후 참여비로 / 원과 학부모가 나눠서 / 현실적으로 어렵다→ 오퍼를 앵커로 '돈 나올 주머니'를 자연스럽게 — 예산 캐묻기 없이
  5. 지금 원에서 하시는 다른 유료 프로그램(영어·체육 등)과 비교하면, 회당 1인 3,900원은 어떻게 느껴지세요? — 부담이 적은 편 / 비슷한 편 / 부담되는 편 / 비교할 프로그램이 없다→ 단가를 캐묻지 않고 비교 앵커로 가격 위치 확인
  6. 원장님 경험상, 이런 요리행사는 아이 1인당 회당 얼마까지면 부담 없이 진행할 수 있는 선일까요? (회당 1인 약 ____원)→ 금액 기준선 — 6개월 해본 뒤라 가정이 아닌 경험 기반 답
  7. ⭐ 만약 내년에 진행한다면 어떤 방식이 우리 원에 맞을까요? — ① 12개월 약정 (1인분 3,900원 · 배송비 무료) / ② 원하는 달만 골라서 (정가 4,900원) / ③ 내년엔 계획이 없다→ 핵심 문항. "하시겠어요?" 대신 3지선다 오퍼 — ③이 있어 거절이 쉬움
  8. (7번에서 ①·②를 고르셨다면) 시작하기 좋은 시점은? (1월 / 3월 새학기 / 기타 ___월) + 예상 참여 인원 약 ___명→ 시작월·인원을 직접 기재 = 자기 원에 대입해 계산했다는 진심의 무게
  9. 내년 프로그램·비용은 보통 몇 월에, 어떤 절차로 확정하시나요? (원장님 결정 / 운영위원회 논의 / 기타)→ 원별 영업 데드라인 — 절차 질문이라 부담 적음
  10. (선택) 이런 프로그램이 어울릴 것 같은 주변 원장님이 계시다면 소개해주실 수 있을까요? (성함·원명·연락처)→ 다른 원으로 퍼질 길 — 실명 소개가 가장 강한 신호
v1.2에서 제거한 문항: 외부 프로그램 전부·단가 나열 / 업체 알게 된 경로 / 부산시 지원금 실집행 / 요리 지출 계정·금액 / 수익자부담 신설 사례 / 원장 모임·단톡방(프라이버시) — 회계 취조·캐묻기 계열 전부 제거(이사님 지침). 대신 4·5번이 오퍼 자체를 앵커로 같은 정보를 자연스럽게 얻는다.
전달 방식 주의: 원장 설문에는 가격이 들어가므로 원장님께 개별 전달(밀봉 봉투 또는 직접) — 선생님이 먼저 열면 "특활비 오른대요"가 학부모 채팅방으로 퍼질 수 있음. 선생님 설문(가격 없음)만 키트 동봉.

② 선생님 설문

목적 한 줄

1년 커리큘럼을 매달 진행할 때 선생님이 힘들지 않도록 키트와 자료를 고치기 위한 것 — 평가·확인이 아니라 도움 요청. 시간 재기·횟수 캐묻기 없음(불쾌·방어적 거짓 응답 방지 — 이사님 지침).

  1. 지금까지 한 요리행사 중 제일 수월하고 아이들 반응도 좋았던 메뉴는 무엇이었나요? (진행한 메뉴 체크리스트에서 선택)→ 성공 메뉴의 성공 요인을 커리큘럼 설계 기준으로
  2. 반대로 다시 하라면 조금 부담스러운 메뉴가 있다면? 어떤 점이 부담이었나요? (준비 / 당일 진행 / 뒷정리 / 아이들이 어려워함)→ 운영 난이도 최악 메뉴를 실명으로 — 2027 배치 전 교체 판단
  3. 만들고 나서 아이들이 잘 안 먹었던 메뉴가 있었나요?→ '만들기는 성공, 시식은 실패' 메뉴 — 편식 개선 가치와 직결
  4. 보내드린 조리도구 중 아쉬웠던 것(수량·크기·품질·세척)이 있다면? 원에 있는 도구를 대신 쓰신 적이 있다면 어떤 것이었나요?→ 실제 대체가 일어난 도구 = 키트의 확정 결함. 유료 전환 전 고쳐야 할 것
  5. 행사 준비부터 뒷정리까지 중에 "이것 하나만 바뀌면 훨씬 편하겠다" 싶은 것 한 가지는?→ 개선 우선순위를 현장이 직접 지목
  6. 요리행사 후에 학부모님 반응이 온 적이 있나요? (하원 때 말씀 / 키즈노트 댓글 / "레시피 알려달라" 문의) 어떤 메뉴 때였나요?→ 학부모를 실제로 움직인 결과물 — 원장님 결제 정당화의 근거
  7. 1년 중 요리행사 하기 힘든 달이 있다면 언제인가요? (원 행사·발표회 겹침 / 신학기 / 방학)→ 여러 원에서 같은 달이 나오면 커리큘럼 해당 월을 저부담 메뉴로 교체
v1.1에서 제거한 문항: 단계별 소요 시간(분) 실측 · 결번 횟수 · 세척 담당자와 시간 · 진행 위임 횟수 · 알레르기 조정 횟수 — 취조당하는 느낌 → 불쾌하거나 거짓 응답 위험. 결번 이력은 원장님 설문 8번으로 이동.

③ 왜 이렇게 짰나

3,900원을 설문 안에 직접 넣은 이유와 안전장치 (v1.2 확정)

설문 기회는 이번 한 번뿐(이사님) — 금액 기준을 이번 설문에서 파악해야 한다. 다만 무상으로 받아온 원의 예의상 긍정을 줄이기 위해 세 가지 장치:

  1. "하시겠어요?" 직문 대신 선택형 오퍼(원장 7번: 약정 3,900 / 단발 4,900 / 계획 없음) — "안 함"이 보기에 있어 거절이 쉽고, 8번(시작월·인원 직접 기재)이 진심의 무게를 더한다.
  2. 금액 기준선은 경험 기반으로(원장 6번) — 6개월 실제 해본 뒤의 "얼마까지가 부담 없는 선"은 가정이 아니라 사후 평가라 믿을 만하다.
  3. 거절 안전핀 명문: "내년 진행 여부와 관계없이 올해 남은 회차는 끝까지 동일하게 진행됩니다."

최종 판정은 후속 행동으로: 설문의 ①(약정) 선택은 관심 표시일 뿐 — 확정은 원장님 통화 → 계약서 서명·시작월·인원 확정으로. ① 선택 3곳+ → 다른 원 마케팅 GO / 0곳 + 4번 "현실적으로 어렵다" 다수 → 가격이 아니라 돈 나올 주머니 문제로 판독.

맘테스트 절충 각주(정직 기록): 원장 4·5·6·7번은 순수 맘테스트 기준으론 의견형이다. 단 ①설문이 한 번뿐 ②응답자가 6개월 실사용 경험자라는 조건에서 가격을 실제 오퍼로 제시하고 고르게 하는 절충 — 이사님 결정(08-24).

⑤ 응답을 어떻게 읽나

  • 8곳은 통계가 아니라 8개의 개별 케이스 — 집계 %가 아니라 원별 반응 단계 + 거절의 구체 이유가 산출물.
  • 성공 기준(미리 정해둠): 유력 2곳 중 1곳+ 계약 + 8곳 거절 이유 지도 + 실명 소개 1건+. 매출(최대 연 수백만 원)은 부산물 — 진짜 산출물은 유료 레퍼런스 원 · 거절 이유 지도 · 소개 네트워크.
  • 선생님 설문의 "부담 메뉴·힘든 달"이 여러 원에서 같은 답으로 수렴하면 → 개별 원 문제가 아니라 커리큘럼 구조 문제 → 해당 월 메뉴 교체.
  • 이 조사가 답 못 하는 것: 모르는 원(콜드)의 전환율·획득 비용 — 8곳은 상한선 참고치. 콜드 검증은 소개받은 원 + 별도 아웃바운드로.
