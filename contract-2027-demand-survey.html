① 원장님 설문

컨셉 = 도움 요청 ("알리려는데 조언을 구합니다")

팔려고 물으면 예의상 답이 나오고, 조언을 구하면 진짜 말이 나온다. 가격 질문도 "당신 지갑" 문제가 아니라 "시장 자문"이 되어 솔직한 금액대가 나온다. 금액은 백지 기입(4번)만 — 설문에는 3,900원·배송비 조건을 노출하지 않는다(앵커가 있으면 답이 쏠림 + 오퍼 제시는 설문 회수 후 원장님 통화에서). 맨 끝(9번)에만 자기 원 이야기로 부드럽게 브릿지.

인트로 문안(초안): "지난 6개월 함께해주셔서 감사합니다. 내년부터는 이 커리큘럼으로 밀프레드를 다른 어린이집에도 알리려고 합니다. 먼저 경험해보신 원장님의 솔직한 조언이 저희에게 가장 큰 힘이 됩니다."

  1. 6개월 해보시니 이 프로그램의 가장 큰 장점은 무엇이었나요? 다른 원장님께 소개한다면 뭐라고 말씀하시겠어요?→ 원장의 언어로 된 세일즈 포인트 — 콜드 영업 카피의 원천
  2. 반대로 아쉬웠던 점, 꼭 보완돼야 할 점은 무엇인가요?→ 유료 전환 전 고칠 1순위
  3. 내년 커리큘럼 표(동봉)에서 빼거나 바꾸면 좋을 메뉴, 추가되면 좋을 메뉴가 있다면? (오븐·에어프라이어 없는 원 기준으로도 봐주세요)→ 커리큘럼 검수를 고객에게 자문받는 형태 — 지정 메뉴 마찰 예방
  4. 다른 어린이집이 부담 없이 시작하려면 1인분에 어느 정도 금액대가 적절할까요? (약 ____원)→ ⭐백지 기입 — 앵커 없이 순수한 시장가 감각. 제3자 관점이라 방어심 없음
  5. [앞치마 드린 원 버전에만 — 안 드린 원은 이 문항 없이 인쇄] 저희가 함께 드린 앞치마·요리사 모자 1년 무상대여(1년마다 새것으로 무상 교체) — 원 입장에서 실제로 가치가 있었나요? — 가치 있었다 / 그저 그렇다 / 없어도 무방하다 + 한 말씀→ 대여 혜택의 실가치 검증(경험 기반) — 오퍼 구성 유지·제외 판단 근거. 안 드린 원에는 앞치마 언급 자체를 하지 않음(이사님 확정 08-26)
  6. 어린이집이 이런 프로그램을 새로 도입할 때 가장 걸리는 부분은 뭘까요? — 비용을 어디서 낼지 / 선생님 부담 / 학부모 동의 / 도입 시기 / 기타→ 예산·절차를 캐묻지 않고 장애물 지도를 자문으로 획득
  7. 내년 준비 일정 — ① 내년 프로그램(요리·체험 등) 계획은 보통 ___월쯤 세우세요? ② 2027학년도 신입 원아 모집·상담은 ___월부터 시작하세요?→ 원별 영업 데드라인 + 모집 홍보 시즌(통례 10~12월) 전 계약 확정 논리의 실측 근거
  8. 경쟁력 자문 — '매달 요리행사가 있는 원'이라는 점, 학부모님이 원을 고를 때 실제로 영향이 있을까요? — 있다(실제 그런 반응·문의가 있었다) / 어느 정도 / 크게 없다 + 이유 한 줄→ 요리행사=차별화 수단 가설의 직접 검증(4월 실측은 '차별화가 1순위 고민'까지만 확인) + 브릿지 직전 배치로 자연스러운 흐름
  9. ⭐ 원장님 원도 내년에 함께해주신다면 어떤 방식이 맞을까요? — ① 연간(12개월) 계약으로 / ② 원하는 달만 그때그때 / ③ 내년엔 어려움 → ①②라면 시작 시점(1월 / 3월 새학기)·예상 인원 약 ___명→ 유일한 자기 원 문항 — 가격 표기 없이 방식만. 구체 조건(3,900원·배송비 무료)은 설문 회수 후 원장님 통화에서 제시. 시작월·인원 기재 = 진심의 무게
  10. (선택) 이 프로그램이 잘 맞을 것 같은 주변 원장님이 계시면 소개 부탁드려요 (성함·원명·연락처)→ "알리려 한다" 컨셉과 자연스럽게 이어지는 소개 요청 — 실명 소개가 가장 강한 신호
전달 방식 주의: 원장 설문에는 유료 전환·금액 이야기가 들어가므로 원장님께 개별 전달(밀봉 봉투 또는 직접) 유지 — 선생님이 먼저 열면 "내년부터 유료래요"가 학부모 채팅방으로 퍼질 수 있음. 선생님 설문(가격·유료 언급 0)만 키트 동봉. 앞치마 안 드린 원 버전은 앞치마 문항 없이 인쇄(원별 버전은 이사님 지정). 종이 출력: A4 1장, 체크박스+짧은 기입칸, 자유서술은 2~3줄 칸.

② 선생님 설문

컨셉 = 도움 요청 · 실무 여정 순서

선생님의 실제 업무 흐름(신청 → 택배·보관 → 자료·준비 → 수업 진행 → 도구 → 뒷정리 → 키즈노트)을 그대로 따라가며 "저희가 어디를 더 도와드려야 하나"를 묻는다 — 자기 하루를 떠올리며 답하기 쉽고, 캐묻는 느낌이 없다. 시간 재기·횟수 세기 없음. 가격 정보 0.

인트로 문안(초안): "내년부터는 다른 어린이집 선생님들도 이 키트로 수업하시게 됩니다. 먼저 6개월 해보신 선생님의 경험이 가장 정확해요. 저희가 어디를 더 도와드려야 할지 알려주세요."

  1. 행사 신청·일정 잡기 — 매달 날짜·수량을 정하고 알려주시는 과정에서 번거로운 점이 있었나요? 어떻게 바뀌면 편하실까요?→ 유료 전환 시 주문 프로세스 설계의 입력
  2. 택배 받기·보관 — 키트 받는 날 불편한 점은 없었나요? (도착 시점 전날/당일 선호 / 박스 안 내용 확인 / 냉장 보관 공간 / 신선도 걱정) 바라는 점은?→ 물류·보관 마찰 — 12개월 정기 배송의 품질 조건
  3. 수업자료·준비 — 수업 전 자료(안내서·영상)를 보고 준비하실 때 부족하거나 헷갈렸던 부분은? 더 있으면 좋을 자료는? (준비 체크리스트 / 시연 영상 / 아이들에게 말해줄 설명 대본)→ 자료 결함과 신규 자료 수요 — 다른 원 온보딩 자료의 설계 입력
  4. 수업 진행 — 아이들과 진행하면서 가장 막히거나 아쉬웠던 순간은? 저희가 무엇을 더 챙겨드리면 수월해질까요?→ 진행 중 마찰의 구체 장면
  5. 조리도구·재료 — 아쉬웠던 도구나 재료(수량·크기·품질)가 있었나요? 원에 있는 도구를 대신 쓰신 게 있다면 무엇인가요?→ 실제 대체가 일어난 도구 = 키트의 확정 결함
  6. 뒷정리 — 정리·세척에서 힘들었던 점은? 어떤 구성이면 편해질까요?→ 숨은 노동 — "세척 최소화 구성" 같은 개선 방향
  7. 키즈노트·학부모 공유 — 행사 후 키즈노트 쓰실 때 시간이 걸리는 부분은? (사진 고르기 / 문구 쓰기 / 아이별로 다르게 쓰기) 저희가 문구 초안·사진 가이드를 드리면 쓰실 것 같으세요? 학부모 반응이 왔던 적이 있다면 어떤 메뉴 때, 뭐라고 하셨나요?→ 학부모를 움직인 결과물 + 키즈노트 자동화(문구 초안) 수요 확인
  8. 메뉴 — 제일 좋았던 메뉴 / 부담스러웠던 메뉴 / 만들고 나서 아이들이 잘 안 먹은 메뉴는? (진행한 메뉴 체크리스트에서)→ 커리큘럼 배치·교체 근거 — '만들기 성공, 시식 실패' 메뉴 특정
  9. 시기 — 1년 중 요리행사 하기 힘든 달이 있다면 언제인가요? (행사·발표회 겹침 / 신학기 / 방학)→ 여러 원에서 같은 달 수렴 = 커리큘럼 구조 문제 → 해당 월 저부담 메뉴
  10. 마지막으로 — 내년에 처음 시작하는 다른 원 선생님들을 위해, 저희가 꼭 준비해야 할 것 한 가지를 꼽아주신다면?→ 도움 컨셉의 마무리 — 개선 우선순위를 현장이 직접 지목
제거 유지(v1.1~): 단계별 소요 시간(분) 실측 · 결번 횟수 · 세척 담당자와 시간 · 진행 위임 횟수 — 취조 느낌 → 불쾌·거짓 응답 위험. v1.3은 같은 정보를 여정 단계별 "불편한 점 + 바라는 점"으로 얻는다.

③ 왜 이렇게 짰나

"도움을 구하는" 프레임 · 가격은 백지 기입만 (v1.4 확정)

설문 기회는 이번 한 번뿐 — 금액 기준을 이번 설문에서 파악하되, 무상 수혜 원의 예의상 긍정을 줄이는 장치 4개:

  1. 도움 요청 프레임: "내년에 다른 어린이집에 알리려는데 조언을 구합니다" — 팔려고 물으면 예의상 답, 조언을 구하면 진짜 말. 가격 질문이 "당신 지갑"이 아니라 "시장 자문"이 된다.
  2. 가격은 백지 기입만(원장 4번): 3,900원·배송비 조건은 설문에 노출하지 않는다 — 앵커가 있으면 답이 쏠리고, 조건 제시는 설문 회수 후 통화에서 하는 것이 협상력도 지킨다.
  3. "하시겠어요?" 직문 대신 방식 선택(원장 9번: 연간 계약 / 원하는 달만 / 어려움 — 가격 표기 없음) — "어려움"이 보기에 있어 거절이 쉽고, 시작월·인원 기재가 진심의 무게를 더한다.
  4. 거절 안전핀 명문: "내년 진행 여부와 관계없이 올해 남은 회차는 끝까지 동일하게 진행됩니다."

최종 판정은 후속 행동으로: 설문의 ①(약정) 선택은 관심 표시일 뿐 — 확정은 원장님 통화에서 3,900원·배송비 무료 조건을 처음 제시 → 계약서 서명·시작월·인원 확정으로. ① 선택 3곳+ → 다른 원 마케팅 GO / 0곳 + 6번 "비용을 어디서 낼지" 다수 → 가격이 아니라 돈 나올 주머니 문제로 판독.

맘테스트 절충 각주(정직 기록): 원장 백지 금액·앞치마 가치·경쟁력·브릿지 문항은 순수 맘테스트 기준으론 의견형이다. 단 ①설문이 한 번뿐 ②응답자가 6개월 실사용 경험자 ③도움 요청 프레임으로 방어심을 낮춘 조건에서의 절충 — 이사님 결정(08-24~25).

④ 조사하며 확인한 제도 사실

오퍼 조건에 직접 영향 주는 것만. 웹검증 완료(2026-08-24).

사실시사점
법령상 '특별활동' = 외부 강사가 진행하는 프로그램. 우리는 담임 선생님 진행 → 특활이 아님특활비 한도(부산 월 8만) 틀을 못 탐 → 행사비·교재교구비 항목이 우리 자리. 계약서·설문에 "특별활동" 단어 금지
부산 학부모 부담 행사비 한도 = 월 1만 원·연 12만 원월 1회 3,900원(연 46,800원)은 한도 안에서 여유
부산 3~5세 필요경비 무상화 — 시가 특활·행사·현장학습비 월 13.7만 규모를 지원(2026~)학부모 주머니보다 시 지원금 안에서 기존 특활 업체와 자리 경쟁이 진짜 게임. 0~2세는 대상 밖(영아 많은 가정어린이집은 불리). 실제 흐름은 원장님 설문 4번으로 확인
원 예산·계약·수납한도가 전부 학년도(3월~다음해 2월) 단위1월 시작 계약은 제도 흐름 역행 + 두 달 뒤 반 편성이 다 바뀜 → 학년도(3월) 시작 권고. 영업 골든타임 = 2026.10 ~ 2027.2
비용·행사는 운영위원회(학부모 절반 이상) 심의 사항원장님 단독 확약 불가 → 운영위 통과용 안건 자료를 우리가 만들어드리면 강력한 영업 도구
참여 강제 금지 · 참여 아동에게만 수납 가능"최소 인원" 조항은 원이 약속할 수 없는 것 → 최소 주문액으로 설계

⑤ 응답을 어떻게 읽나

  • 8곳은 통계가 아니라 8개의 개별 케이스 — 집계 %가 아니라 원별 반응 단계 + 거절의 구체 이유가 산출물.
  • 성공 기준(미리 정해둠): 유력 2곳 중 1곳+ 계약 + 8곳 거절 이유 지도 + 실명 소개 1건+. 매출(최대 연 수백만 원)은 부산물 — 진짜 산출물은 유료 레퍼런스 원 · 거절 이유 지도 · 소개 네트워크.
  • 선생님 설문의 "부담 메뉴·힘든 달"이 여러 원에서 같은 답으로 수렴하면 → 개별 원 문제가 아니라 커리큘럼 구조 문제 → 해당 월 메뉴 교체.
  • 이 조사가 답 못 하는 것: 모르는 원(콜드)의 전환율·획득 비용 — 8곳은 상한선 참고치. 콜드 검증은 소개받은 원 + 별도 아웃바운드로.

⑥ 이사님 확정 대기 6건

확정됨: 횟수 = 월 1회 × 총 12회 · 오퍼는 설문에 포함(v1.2) · 시작 시점은 원장 8번이 수집. 남은 결정:

  1. 지정 강도: 완전 지정 vs 월 2메뉴 중 원이 택1 — 권고 = 택1 (원장님들 최대 관심사가 '우리 원 차별화'라 자율성 완전 박탈은 반감)
  2. 계약 단위: 1~12월 vs 학년도 3월~2월 — 권고 = 학년도 (§④ 제도 흐름 + 원장 8번 응답 분포 참고)
  3. 최소 주문: 인원 조항은 제도상 불가 → 최소 주문액 설정 여부·수준 (에이든 12명·유경 14명이 하한 검증 케이스)
  4. 결제 주기: 월별 정산 vs 선납 — 기존 "계산서 계좌이체 5% 할인"과 3,900원 중복 적용 여부 포함
  5. 진행 못 한 달 처리: 할인 취소? — 권고 = 그 달 안 대체일 + 완충(예: 연 10회 이상 진행하면 할인 유지)
  6. 대원칙.md 개정 승인: 월간 페인 탐색 설문 시대 종료 + 계약 검증 단계 진입 명문화
