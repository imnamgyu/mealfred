계약 단위: 늘봄·방과후 = 연 단위 용역 입찰(나라장터·S2B) vs 진로체험 = 회당 행사·출강(꿈길 매칭·학생 1인 1.4~1.8만원). 의사결정자: 교장·교육청 vs 진로전담교사·진로체험지원센터(전국 219곳·경기 31). 겸업은 표준(참교육 명함 그대로 — 대교에듀캠프 드림멘토·더 참교육 사협은 꿈길에 유료 3건 등록) → 별도 버킷 + '겸업 태그'로 교차 관리

꿈길 실측 (08-24, API 직접 호출)

활성 프로그램 19,461건 = 고유 체험처 5,592곳(개인사업장 60% — 공방·학원급). 경기 2,690건·화성 86건·부산 1,410건. 로그인 없이 검색·엑셀 다운로드 가능(연락처 컬럼은 없음). 체험처명 전수에서 '대교' 0건·'방과후' 0건 → 위탁운영사 리스트 소스로는 부적합(하). 위탁사 리스트 정답 소스 = 입찰 개찰기록 + coop.go.kr 품목검색 + 늘봄허브 공급기관 + 채용공고(= 이 지도의 방법)

대신 — 우리의 직판 채널

꿈길 '요리' 프로그램 499건(부산 46·화성 0) · 늘봄허브 '요리'는 전국 18건뿐 = 공급 공백. 우리가 꿈길 진로체험처(무료 등록·유료 판매 허용, 관할 센터 승인제) + 늘봄허브 기관 프로그램(다음 심사 10월)에 직접 등록 → 위탁운영사들에게 '검증된 공급사'로 역제안 가능. 교육기부 인증제(누적 2,627곳)는 연 4회 무료 제공 의무 유의
